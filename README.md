# Sales Performance Dashboard

## Problem Statement
Businesses need clear visibility into sales performance to track growth, profitability, and product performance.

##  Objective
To build an interactive dashboard that analyzes sales, quantity sold, and gross profit over multiple years.

##  Tools Used
- Power BI
- Power Query
- DAX

## Dashboard Features
- Year-over-year sales comparison  
- Gross profit analysis  
- Product and category performance  
- Sales trends over time  

##  Key Insights
- Identified top-performing product categories  
- Seasonal trends affecting sales volume  
- Regions contributing the highest revenue  

##  Business Value
This dashboard helps management:
- Monitor overall business growth  
- Identify profitable products  
- Make data-driven sales and marketing decisions
